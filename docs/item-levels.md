# Equipment level curves

Each cell lists level:value breakpoints. A value followed by an exponent in parentheses sets the curve toward the next breakpoint. Weight curves use (zero-mass power ratio, cutoff mass, half-power step) at each breakpoint.

For adjacent levels L and R, t = (level - L) / (R - L). The interpolated value is leftValue + (rightValue - leftValue) * t^p. The exponent p is 1 when omitted. The last value holds above the last breakpoint. [Stat interpolation](../src/reg/Stat.as#L27), [interpolate](../framework/lbg/utils/NumberUtils.as#L48)

When a level has conflicting entries, the first value wins at that exact level. Between levels, the first adjacent pair that brackets the level supplies the curve. For example, Dubstep Drive costs $2,800 at level 0, and its next price segment starts from $2,100. [Lookup order](../src/reg/Stat.as#L55), [Dubstep Drive](../src/reg/Registry.as#L3921)

Slot counts hold until the next breakpoint. Prices are raw before [price rounding](../src/reg/StatNice.as#L21). [Slot steps](../src/reg/StatFlat.as#L43), [field defaults](../src/reg/RegistryEntry.as#L33)
